Echobell は Webhook とメールをスマートフォンの即時プッシュ通知に変えます。重要なアラートは着信のように鳴らせるので、障害が通知シェードの中で見過ごされることがありません。

HTTP リクエストを 1 回送るだけで、スマホが気づきます。開発者、SRE と運用担当、個人開発者、セルフホストやホームラボの利用者、トレーダー、そして本当に届くアラートが必要な少人数チームのために作られています。

3 段階の通知レベル
• 標準 — 日常的なイベント向けの通常のプッシュ通知
• 時間指定 — 優先度が高く、より早く気づける
• 着信 — 重要なアラートを電話の着信のように鳴らす

チャンネルとダイレクトキー
• チャンネルは同じ種類のアラートをまとめ、テンプレートと条件を持ち、購読リンクを共有すればチーム全員が一度に購読できます
• ダイレクトキーは、スクリプト・cron・一時的な連携のための専用 Webhook URL です
• チャンネルは Webhook リクエストでも、チャンネル宛のメール送信でも起動できます

すべてのアラートを読める形に
• タイトルと本文のテンプレートが、生の JSON ペイロードをそのまま行動できる一文に変換します
• 条件でノイズを除外し、本当に重要なイベントだけを通知にします
• リンクテンプレートで、アラートから該当のダッシュボード・チャート・手順書・障害ページへ直接移動できます
• 通知履歴は端末内に保存され、いつでも見返せます

主な用途
• サーバー監視、死活監視、ダウンとリカバリの通知
• 本番障害、API エラー、オンコール呼び出し、ステータス変更
• CI/CD パイプライン、デプロイ通知、ビルド失敗、リリースイベント
• cron ジョブ、バックアップ、スケジュール実行、ハートビート監視
• スマートホーム、セルフホストサービス、NAS、ホームラボのセンサー
• 株式や暗号資産の価格アラート、売買シグナル、戦略スクリプト
• 小規模ビジネスの決済・注文・顧客イベント
• セキュリティイベント、ログインアラート、監査シグナル

いまの構成のまま使えます
HTTP リクエストを送れるものなら何でも Echobell の通知を送れます。シェルスクリプト、Python、Node、自動化プラットフォーム、監視スタック、死活監視サービス、CI ランナー、スマートホームハブ、取引ボットなど。SDK のインストールも常駐エージェントも不要です。

プレミアム
Echobell プレミアムでは、チャンネルとダイレクトキーが無制限になり、着信スタイルのアラートが使えます。招待ポイントをプレミアム期間と交換することもできます。

Echobell は監視スタックや自動化基盤、インシデント管理ツールを置き換えるものではありません。それらに素早いモバイル通知の層を足し、本当に重要なイベントを、実際に持ち歩いている端末まで届けます。
