Echobell은 웹훅과 이메일을 휴대폰의 즉시 푸시 알림으로 바꿔 줍니다. 중요한 알림은 전화 수신처럼 울릴 수 있어서, 장애가 알림 목록 안에서 조용히 묻히지 않습니다.

HTTP 요청 한 번이면 휴대폰이 바로 알아챕니다. 개발자, SRE와 운영 담당자, 1인 개발자, 셀프호스팅과 홈랩 사용자, 트레이더, 그리고 실제로 도달하는 알림이 필요한 소규모 팀을 위해 만들었습니다.

세 가지 알림 강도
• 표준 — 일상적인 이벤트를 위한 일반 푸시 알림
• 시간 민감 — 우선순위가 높아 더 빨리 눈에 띕니다
• 전화 — 중요한 알림을 전화 수신처럼 울립니다

채널과 다이렉트 키
• 채널은 같은 종류의 알림을 묶고, 템플릿과 조건을 가지며, 구독 링크 하나로 팀 전체가 구독할 수 있습니다
• 다이렉트 키는 스크립트, cron 작업, 임시 연동을 위한 전용 웹훅 URL입니다
• 채널은 웹훅 요청으로도, 채널 주소로 이메일을 보내서도 실행할 수 있습니다

모든 알림을 읽을 수 있게
• 제목과 본문 템플릿이 원시 JSON 페이로드를 바로 행동할 수 있는 한 문장으로 바꿉니다
• 조건으로 잡음을 걸러, 정말 중요한 이벤트만 알림이 됩니다
• 링크 템플릿으로 알림에서 바로 해당 대시보드, 차트, 대응 문서, 장애 페이지로 이동합니다
• 알림 기록은 이 기기에 저장되어 언제든 다시 확인할 수 있습니다

이런 곳에 사용합니다
• 서버 모니터링, 헬스 체크, 다운과 복구 알림
• 운영 장애, API 오류, 온콜 호출, 상태 변경
• CI/CD 파이프라인, 배포 알림, 빌드 실패, 릴리스 이벤트
• cron 작업, 백업 작업, 예약 작업, 하트비트 모니터링
• 스마트홈, 셀프호스팅 서비스, NAS, 홈랩 센서
• 주식과 가상자산 가격 알림, 매매 신호, 전략 스크립트
• 소규모 사업의 결제, 주문, 고객 이벤트
• 보안 이벤트, 로그인 알림, 감사 신호

지금 쓰는 도구 그대로
HTTP 요청을 보낼 수 있으면 무엇이든 Echobell 알림을 보낼 수 있습니다. 셸 스크립트, Python, Node, 자동화 플랫폼, 모니터링 스택, 헬스 체크 서비스, CI 러너, 스마트홈 허브, 트레이딩 봇까지. 설치할 SDK도, 상주 에이전트도 없습니다.

프리미엄
Echobell 프리미엄은 무제한 채널, 무제한 다이렉트 키, 전화형 알림을 제공합니다. 초대 포인트로 프리미엄 기간을 교환할 수도 있습니다.

Echobell은 모니터링 스택이나 자동화 플랫폼, 장애 관리 도구를 대체하지 않습니다. 거기에 빠른 모바일 알림 계층을 더해, 정말 중요한 이벤트가 실제로 들고 다니는 휴대폰까지 도달하게 합니다.
