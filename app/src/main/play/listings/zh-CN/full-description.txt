Echobell 把 Webhook 和邮件变成手机上的即时推送通知，重要告警还能像来电一样响铃，故障不会静静躺在通知栏里没人看见。

发一个 HTTP 请求，手机立刻知道。Echobell 面向开发者、运维与 SRE、独立开发者、自建服务和家庭实验室玩家、量化交易者，以及需要真正能叫醒人的告警的小团队。

三档提醒强度
• 标准通知 —— 常规事件的普通推送
• 时效通知 —— 优先级更高，更容易被第一时间看到
• 来电提醒 —— 关键告警像来电一样响铃

频道与直连密钥
• 频道用来归类同一类告警，可配置模板与触发条件，还能生成订阅链接让整个团队一键订阅
• 直连密钥是给单个脚本、定时任务或临时集成用的专属 Webhook 地址
• 频道既可以用 Webhook 请求触发，也可以通过向频道邮箱发邮件触发

让每条告警都能直接读懂
• 标题与正文模板把原始 JSON 负载渲染成一句能直接行动的话
• 触发条件过滤噪音，只有真正重要的事件才会变成通知
• 链接模板让你从告警一步跳转到对应的监控面板、行情图、处置手册或故障页
• 通知记录保存在本机，随时回查

大家都用 Echobell 做什么
• 服务器监控、可用性探测、宕机与恢复告警
• 线上故障、API 报错、值班呼叫与状态变更
• CI/CD 流水线、部署通知、构建失败与发版事件
• 定时任务、备份任务、计划作业与心跳监控
• 智能家居、自建服务、NAS 与家庭实验室传感器
• 股票与加密货币价格提醒、交易信号与策略脚本
• 小微商家的收款、订单与客户事件
• 安全事件、登录提醒与审计信号

不用改造现有工具链
只要能发 HTTP 请求，就能发 Echobell 通知：Shell 脚本、Python、Node、自动化平台、监控系统、可用性探测工具、CI 执行器、智能家居中枢和交易机器人都可以。不需要安装 SDK，也不需要常驻 Agent。

高级版
Echobell 高级版解锁无限频道、无限直连密钥与来电式提醒，也可以用邀请积分兑换高级版时长。

Echobell 不打算取代你的监控系统、自动化平台或故障管理工具，而是给它们补上一层快速的移动端告警通道，让真正重要的事件送达你随身带着的那台手机。
